# Content Operations Dashboard Demo

This standalone demo preserves the interface and interaction model of production Apps Script deployment `@336`, while replacing every embedded dataset with deterministic synthetic fixtures.

- All people, accounts, vendors, links, metrics, comments, and source records are fictional.
- The page does not connect to Apps Script, Google Sheets, analytics, or any other backend.
- Missing values remain distinct from confirmed zero values.
- The static page is suitable for GitHub Pages.

Open `index.html` directly or serve this directory with any static web server.
